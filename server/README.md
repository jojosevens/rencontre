# Node.js/Express scaffold — THEOTOKOS

Ce dossier contient un scaffold minimal d'API prête pour :
- Auth (signup/login) utilisant bcrypt + JWT
- Endpoints utilisateurs
- Socket.io setup pour le chat

Ceci est volontairement minimal et destiné à être complété pour production (validation, rate limiting, stockage sécurisé des secrets, email verification via SendGrid, etc.).
