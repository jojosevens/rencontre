# THEOTOKOS — Hybrid Auth & Backend scaffold

Cette branche contient :

- Une intégration client rapide (Supabase) pour prototyper l'auth et le chat realtime.
- Un scaffold Node.js/Express minimal (API auth + sockets) prêt à être développé et déployé pour production.
- Documentation pas-à-pas pour configurer Supabase et lancer le serveur local.

Objectif : permettre un prototype rapide avec Supabase tout en offrant une voie de migration vers une API self-hosted.
